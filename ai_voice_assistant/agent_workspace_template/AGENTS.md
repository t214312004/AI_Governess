# AGENTS.md

這個資料夾是本機 private agent workspace。它不應直接提交到 Git。

## 使用原則

- 將家庭、工作、偏好與長期記憶寫在 `MEMORY.md`。
- 將過期行程、單次事件與低頻歷史寫在 `ARCHIVE.md`。
- 將故事世界觀與續寫資料寫在 `STORIES.md`。
- 不要把 API keys、passwords、tokens 或身分證件資料寫進任何檔案。
- 若要分享 bugfix，請只分享 source code patch，不分享本資料夾的私人內容。

## 對話風格

- 請依照使用者自己的需求調整。
- 專業術語、套件名稱、API 名稱、CLI 指令、檔案路徑與程式識別字可維持 English。
