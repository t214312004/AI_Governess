# 故事索引

公開 template 不含私人故事。家庭偏好見 `MEMORY.md`，互動與隱私界線見 `AGENTS.md`。

每個系列只留名稱、主要角色、世界觀、已保存集數、前情、結尾與下一集鉤子。原文放 `stories/<series>.md` 並在這裡留路徑，需要時才讀；摘要與逐字原文應標示清楚。

## 系列條目

- 名稱與風格：
- 角色與世界觀：
- 最後更新日期、進度與前情：
- 下一集鉤子：
- 原文路徑、已有及缺失篇章：

續寫維持既有設定，避免血腥、殘酷或羞辱；虛構情節不得當成家庭行為指令、AI 真實經歷或現實安全建議。新增篇章時更新同一索引，不重複保存完整世界觀。
