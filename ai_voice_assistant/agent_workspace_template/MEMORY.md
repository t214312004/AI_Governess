# 活躍記憶層

這個檔案保存會在未來互動中反覆影響判斷的穩定資訊。它是公開 template；複製到 `agent_workspace/MEMORY.md` 後，實際內容會變成本機 private data，不應直接提交到 Git。

---

## 使用與更新原則

- 只保存長期有用、已確認、可中性摘要的資訊。
- 不保存一次性的情緒、玩笑、誤聽、臨時猜測、短期行程或不需要長期記憶的細節。
- 若使用者明確說「記住」，仍要先判斷是否適合長期保存；不適合時可以改放 `ARCHIVE.md` 或不保存。
- 若資訊可能影響安全、公平、隱私、身份判定或家庭互動品質，優先整理到本檔。
- 若本檔與當前對話衝突，以當前對話為準，並在確認後更新本檔。
- 不要保存 API keys、passwords、tokens、身分證件資料、付款資訊或其他敏感秘密原文。
- 寫入中文內容時維持 UTF-8 無 BOM；若使用 PowerShell 追加，務必明確使用 UTF-8 encoding。

---

## 維護提醒

- 新資訊若只是單次事件或低頻細節，優先追加到 `ARCHIVE.md`。
- 新資訊若會在接下來幾天到幾週持續影響互動，整理後放入本檔。
- 新資訊若幾乎每次互動都可能影響安全、公平、隱私或人格設定，應同步摘要到 `AGENTS.md`。
- 定期清理過期的活躍議題，避免本檔變成流水帳。
