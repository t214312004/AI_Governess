# 第一次設定愛管家

## AI 服務

先選已安裝並登入的 CLI，再按「查詢模型（不更新）」。找到 CLI 只代表執行檔存在；查詢成功後才能選模型與推理強度。等待時可按「取消查詢」。

| 服務 | 安裝與登入 |
| --- | --- |
| Codex CLI | 依 [OpenAI Docs：Codex CLI](https://learn.chatgpt.com/docs/codex/cli) 選 Windows 安裝方式。安裝後執行 `codex login` 完成瀏覽器登入；可用 `codex login status` 檢查。見 [官方認證說明](https://learn.chatgpt.com/docs/auth)。 |
| Claude Code | 依 [官方 Windows 安裝說明](https://code.claude.com/docs/en/setup) 安裝，再執行 `claude` 並依瀏覽器提示登入。 |
| OpenCode CLI | 依 [官方文件](https://opencode.ai/docs/) 安裝並完成所用模型提供者的連線設定。 |
| Grok CLI | 依 [官方 Grok Build 文件](https://docs.x.ai/build/overview) 安裝與設定；本專案的 Windows PATH 設定見 [README](../README.md#grok-build-backend)。 |
| Antigravity CLI | 依本專案 [安裝流程](../README.md#antigravity-cli-安裝) 完成 `agy` 安裝與首次授權。 |

新安裝後請重新開啟 PowerShell 與本程式，讓 PATH 生效。CLI 的帳號由各 CLI 管理，不是在語音服務的 Google／Groq key 欄位登入。

「更新 CLI 並查詢模型」是選用操作；若更新失敗，仍可選擇只查詢。不同安裝來源的更新方式可能不同，請依官方文件處理。

不必先完成登入才能保存其他設定。各頁底部的「儲存設定」會把有效草稿寫入本機 `config.local.json`，稍後可回來查詢模型與啟動。

## 聲音與裝置

輸入與輸出可分開選。純文字模式不需要語音服務或麥克風；選語音後才顯示所需設定。

- 麥克風／喇叭可選 Windows 預設或指定裝置與 host API。重新插拔後按「重新偵測裝置」。指定裝置離線會提示重新選擇，不會默默改用另一支麥克風。
- Local Whisper：設定模型、CPU／CUDA、運算精度與語言；CPU 通常可從 small、int8 開始。`auto` 表示自動判斷語言。進階取樣率僅支援 8000／16000 Hz，收音區塊分別使用 256／512 samples。
- Groq：在服務下方填 key 或使用所列環境變數，再選辨識模型。Groq key 隨「儲存設定」或啟動保存。
- Gemini：先設定上方 Google key，再選模型與音色。Google key 的儲存／刪除立即生效，不影響環境變數。詞彙提示可逐項增刪。
- Edge：選音色，用滑桿調整語速與音量；音量 100% 為原音量。
- BlueMagpie：選用即啟用，畫面會列出缺少的 worker 檔案；環境與模型準備見 [BlueMagpie 指南](bluemagpie_tts_setup.md)。參考音檔與逐字稿需成對提供。

「檢查所選裝置」確認裝置與格式；再用 5 秒錄音觀察收音指示並執行辨識，用試聽確認實際播放。雲端辨識／試聽會使用對應服務。停止、修改或切頁會取消目前測試；修改後需要重新測試。

## 互動與使用限制

- HTML 額度 0 表示停用 HTML；上限 1440 分鐘，Asia/Taipei 每日 00:00 重置。Markdown／圖片不限時。
- 對話字級可選 16–32 px，畫面有預覽。
- 接續聆聽、主動詢問、定時關懷、錄音保存及聲紋開關集中於此。
- 「編輯喚醒詞」直接讀寫設定的詞檔，儲存前驗證格式及模型 tokens。每行格式為 `發音 tokens :加權 #門檻 @名稱`，例如 `ài g uǎn j iā :3.0 #0.15 @愛管家`。修改名稱時也要提供模型對應的發音 tokens，再用「錄音測試喚醒詞」驗證。缺少模型時仍可手動收音。
- 「新增家人／錄製聲紋」輸入姓名，再匯入音檔或錄音 5 秒。樣本必須達到最短秒數且有足夠音量，轉為 WAV 儲存在本機 profile 目錄；可為同一人追加樣本。
- 角色指令與私人記憶有獨立編輯器，按儲存才改檔。喚醒詞、聲紋、角色檔案的保存立即生效，與 wizard 草稿分開。

## 進階選項

預設只顯示目前服務的細節，可勾選「包含其他服務與基本設定欄位」。可搜尋當前或全部分類；路徑可瀏覽，文字提示可多行編輯，清單可逐項增刪。Seed 留白或按「使用隨機值」可恢復隨機。

錯誤會標出欄位並捲至該處；「還原此分類預設值」可回復該分類可見設定。未知本機設定仍保留。全螢幕快捷鍵固定為 Alt+F4。

## 確認與啟動

確認頁區分模型查詢、裝置格式、辨識、試聽、喚醒詞、金鑰來源與本機資源。未測試不代表通過，也不一定表示故障。

啟動失敗可用「錯誤詳情」查看階段與經遮罩的原因，修正後重試。準備失敗會回復此次啟動前的設定，之前明確儲存的設定仍保留。正式畫面若要更換服務或裝置，請 Alt+F4 關閉後重新設定。
