## 已修正的問題

### 音訊播放

- 帶有 generation 的原始 ndarray 在排入佇列後丟失 generation，導致換回合後仍可能播放舊音訊；現在保留在 `PlaybackChunk`。
- callback 已取出的殘餘 PCM 沒有再次檢查 generation；換回合後現在丟棄舊殘餘音訊。
- finished callback 清除 active stream 後，後續 stop/reset 無法 close 該 stream；現在保存待清理 stream，在 callback 以外的執行緒 close。

### 主流程與定期工作

- 播放佇列有容量限制時，`play()` 的等待會阻塞 asyncio loop；主流程現在透過 `asyncio.to_thread()` 排入播放佇列。
- 文字回覆正常結束但內容為空時，沒有走 failure 記錄與 session refresh；現在一致處理為 `empty_response`。
- heartbeat／排程讀取下一個 LLM chunk 時，外層 task 被取消可能留下仍在執行的 `__anext__` task，使 generator 無法關閉；現在取消並等待 reader 清理。

### LLM transport

- ACP 把連續相同的合法文字 delta 當作重複訊息丟棄；現在保留這些 delta，同時保留工具切換後既有的 replay-prefix 處理。
- ACP 啟動時遭取消沒有進入 subprocess 清理；現在 `CancelledError` 也會清理並向上傳遞。
- 尚未 ready 的既有 subprocess 會讓 `_start_acp()` 提早返回；現在清理失敗的啟動，再重新初始化。
- stdout reader 結束後，ready 狀態仍可能有效；現在清除 ready，下一次 `ensure_ready()` 會重新啟動。
- ACP、Codex、Claude 收到合法 JSON 的 list/null 等非 object 訊息時會進入不適用的 object 處理；現在跳過非 object。

### TTS

- Edge／BlueMagpie 忽略 `audio_player.play()` 的拒絕結果而回報成功；現在回傳 `playback_rejected`。
- BlueMagpie 部分音訊排入後遭中斷仍可能回報播放成功；現在回報中斷。
- BlueMagpie 寫入／讀取 worker 請求遭取消後，舊回覆可能被下一個請求讀到；現在終止該 worker，避免沿用已錯配的 stdout。
- registry 接受的 `blue_magpie`、`bluemagpie_tts` 別名，在 factory 被當成 Edge；現在 factory 與 UI 共用相同別名解析。
- Edge MP3 解碼沒有轉換成設定的輸出取樣率，非 24 kHz 播放時速度與邊界時間錯誤；現在 resample 並 flush 剩餘 PCM。
- 浮點 PCM 超過 ±1 時，直接轉 int16 會溢位反轉；現在先 clip。取樣率測試使用記憶體中的真實 MP3 編解碼，沒有網路或音訊裝置依賴。

### 排程與報告

- 每週排程接受空 weekday list，無法得到可執行時間；現在要求至少一天。也拒絕 bool 或有小數的 weekday，避免被 `int()` 誤轉成有效星期。
- JSON 根節點為 list/null 時，會污染整批排程／報告讀取；現在驗證 object，既有 iterator 會跳過無效檔案。
- 已確認的 draft 仍可被取消並宣稱沒有建立排程，但正式排程實際已存在；現在拒絕取消已處理 draft。
- 完成 claim 時把報告本文所有空白壓成單一空格，破壞段落、條列與 Markdown；現在保留正文內的換行與格式。
- 執行中的 schedule 仍可 enable/disable，破壞 claim 的狀態一致性；現在與 update/delete 一樣拒絕更動 active claim。

### 白板、UI 與素材工具

- Markdown 資產遺失會回傳成功與空內容，路徑成為目錄或 UTF-8 損壞會拋例外；現在回傳 `blocked` 並說明讀取失敗。
- UI 編輯 once 排程時只回填日期，時間變成表單預設值，timezone 也被強制改成台北；現在回填 `run_at` 的時間並保留原 timezone。
- `WH_KEYBOARD_LL` 收到所有程式的鍵盤事件，原本未判斷前景視窗；現在只在本 app 位於前景時攔截，切到其他程式會釋放 HTML capture。測試模擬 native hook callback，確認遊戲鍵與 Windows 鍵都能傳給其他 app。
- 動畫素材工具在檢查 `--source-columns` 前已覆寫 `background.png`；現在先驗證參數並準備來源資料，再開始寫入，避免驗證失敗破壞既有背景。
