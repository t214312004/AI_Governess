## 預覽

[開啟 v8](http://127.0.0.1:5187/shared-face.html?expression=1)，先切換「說話／v7 參數對照」與「說話／眉眼校準後」。兩者只改參數，使用同一個 `expression-face/original.moc3`，沒有換模型或整頭圖。展開「與原圖校對」，選說話影格後套用表情，可看原圖、50% 疊圖和差異 ×4。參考圖維持來源座標，未移動或拉伸來降低誤差。

「慢速眨眼檢查」可檢查新眼型下的半閉眼；「播放連續表情與視線」會連續組合新舊控制。播放音訊時，開口依實際音訊驅動，其他表情仍可操作。[無聲錄影](../reports/g2/expression-v8.webm) 展示校準前後的連續變化、慢速閉合及新組合；錄影本身不含音訊同步驗收。

## 結構與來源

保留 v7 的共用臉底、20 個 ArtMesh 與全部 PNG 拆件；不新增圖像素材。由原生 PSD2Live 開啟已接受 v7 工程，新增外層 Warp 和參數後，另存 `authoring/shared-face/shared-face-rig-v8-expression.psd2live` 及 PSD，再匯出標準 Cubism 模型。

| 新參數 | 範圍 | 控制內容 |
|---|---|---|
| `ParamEyeRForm` / `ParamEyeLForm` | −1～1 | 各側眼型的微幅比例、角度與位置；整組眼皮、睫毛、眼白、虹膜、摺線共同變形 |
| `ParamBrowRForm` / `ParamBrowLForm` | −1～1 | 各側眉形的微幅比例、角度與位置；可與既有眉高、眉角組合 |

新四軸加上既有十一個控制，共十五個。R／L 指角色自身側別。各軸在 0 保留 v7 表現；這些是沿來源輪廓校準方向的組合變形軸，並非任意五官形狀都能精確還原的通用控制。

`tools/fit-feature-contours.py` 只分析來源像素，擷取待機／說話影格的暗色輪廓，估計受限的位移、比例和旋轉；結果在 `design/feature-contour-fit.json`。`tools/rig-expression-face.py` 透過原生工具建立外層變形器，把虹膜、眼白與摺線以保持畫布位置的方式綁入同側眼部群組，保留原有開合與視線 keyforms。眉部外層包住既有眉形變形器。

`tools/fit-expression-reference.mjs` 在模型固定後只尋找參數，不改模型或來源圖。最終候選參數在 `design/expression-reference-poses.json`。本輪沒有使用 ImageGen；目前修正是 rig 幾何與參數校準，沿用既有部件即可。

## 回歸與組合檢查

`npm.cmd run test:expression` 包含：

- 22 組既有參數，與已接受 v7 逐 ArtMesh 比較；新四軸為 0 時，來源座標頂點差小於 0.06 px，透明度及遮罩一致。
- 四個新軸各五點取樣；左右眼眉獨立，不改其他部件幾何。
- 3 組眼型 × 3 組斜向視線 × 7 個開合，共 63 組，並疊加嘴形、嘴寬及開口；虹膜不隨閉合壓扁，遮罩正確，下唇保持可見。
- 新眼型可能旋轉眼部，因此先用開眼幾何求外層 affine 轉換，再將閉合軌跡還原至眼部座標測量；擬合殘差須小於 0.05 px，睫毛／眼皮閉合中心差仍須小於原有 0.35 px。測量輔助另有旋轉、非等比縮放及退化幾何測試，沒有以放寬容許值處理警示。
- 音訊嘴型與新眉眼軸可同時運作，停止閉嘴，連續序列確實使用新軸，整頁模型只載入一次、瀏覽器無例外。

半閉眼和全閉截圖、校準後說話截圖及無聲錄影另作視覺檢查；數值通過不代替使用者質感驗收。[來源保護報告](../reports/g2/expression-asset-integrity.json) 驗證 v5／v6／v7 備份與現行模型未變，以及本輪測試、錄影使用相同模型。

## 後續範圍

目前眼型比原先更接近說話來源，但眉形只小幅改善，鼻形、臉部明暗及其他表情仍不一致。需繼續逐張校對可重用五官變形；若現有控制不足，再補局部 rig 或部件。頭頸、手臂、七手勢和拇指／虎口／指節的連續動作也尚未接入此臉部模型。完成這些並通過質感驗收後，才考慮主程式整合。
