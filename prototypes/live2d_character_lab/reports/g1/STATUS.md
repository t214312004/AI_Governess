# G1 實作與實測紀錄

更新：2026-11-12。**G1 部分完成，尚未通過全套手勢與質感門檻。主程式未修改。**

## 可以執行的成果

1. `index.html`：愛管家原圖經 See-through 拆件，再用 PSD2Live 3.6.7 匯出，官方 Cubism SDK for Web 5-r.5 顯示。22 個 ArtMesh、20 個參數，支援頭身微動、眨眼、音訊控制嘴部。五狀態按鈕目前控制表情及頭身姿態，**不是全部手勢完成**。
2. `arms.html`：imagegen 中立姿勢 → 本機 PSD2Live 分割上臂、前臂、手掌 → 六個肢體骨加軀幹 → moc3。可連續拖曳「手靠下巴 → 放下 → 抬手」，每次只載入一份手臂模型。這是另一個工程實驗樣本，沒有可動眼嘴，不作最終完整單模型交付。
3. 已保存可編輯工程 `authoring/governess-base.psd2live`、`arm-spike-clean.psd2live`、分層 `arm-segments.psd`，並保留之前試驗版本供比較。手臂工程已成功以 PSD2Live 重開，骨架與角度範圍仍在；**尚未以 Cubism Editor 開啟 cmo3**。

## 已驗證與證據

- `npm.cmd run build`：獨立 Vite build，包含嘴型頁與手臂頁。
- `npm.cmd test`：3 個測試通過，涵蓋 20 組有向狀態切換、音量包絡與不同更新頻率的嘴型平滑。
- `npm.cmd run test:browser`：使用獨立 headless Edge；詳見 [結果](browser-results.json)。測試會拒收錯誤參數名稱、模型未顯示、嘴部無網格及重載模型。
- 對同一組其他參數，只改 `ParamMouthOpenY` 由 0 到 1：271 個嘴部頂點中最大座標差約 0.0106 模型單位，確認變形進入 Core。這是功能證據，**不是聲畫延遲或嘴型自然度已驗收**。
- 實際播放新的本機合成測試音訊可開口，暫停、靜音、停止時閉嘴；不使用真人追蹤。
- 手臂頁的五個轉場抽樣由官方 Core 渲染，檢查有限座標、網格位置改變及不重載；截圖供視覺檢查，不能自動判定無穿模。
- SDK 與 PSD2Live 下載 SHA-256 已由 `tools/setup-tools.ps1` 驗證。模型與源素材 hash 見 `artifact-hashes.json`。

## 視覺檢查與失敗經驗

| 項目 | 實際結果 | 後續處理 |
|---|---|---|
| 原圖 See-through | 基礎頭部可用；交疊手沒有完整拆成兩套獨立手臂 | 中立姿勢補件與重新拆分 |
| imagegen neutral_v1 | 手臂分離，但多了衣服口袋、有透明邊緣雜點 | v2 已移除口袋；邊緣仍待修正 |
| 整條手臂綁骨 | 大角度時袖子大幅拉伸 | 否決此試驗版本 |
| 原位分割後保留舊 rig | 切割後的繼承拓撲／綁定仍造成拉伸 | 分層 PSD 匯出再重新建模後明顯改善；初步推定與繼承資料有關，未定位上游 bug |
| 新建分段骨架 | 肩、肘、腕可動，手可定位至下巴附近及抬起 | 肩線缺口、肘部接縫、袖側殘留線段仍不合格 |
| 手掌與語意 | 目前都是放鬆手掌 | 托腮、食指、耳旁聆聽等需要專用差分 |
| 自動 IK | 某些解會選擇不自然的肘部方向 | 原型使用選定肘朝下分支的二段解析解；正式動畫須修曲線與遮擋 |

原生與官方 runtime 的截圖保存在本資料夾（PNG 未加入 Git）。`governess-preview.png`、`mouth-open.png` 為基礎嘴型示範；`arm-transition-*.png` 為官方 runtime 的手臂轉場；`arm-chin-render-0.png` 和 `arm-segmented-*.png` 是失敗版本，不能當完成圖。

## 外部限制與待完成工作

See-through 第二輪要求 180 秒 GPU 額度，服務回報剩餘 117 秒，因而拒絕執行。沒有更換帳號或規避額度；改用本機 native source splitting 繼續工程試驗。外部服務恢復後仍需重新審查拆件品質，不以可呼叫取代驗收。

接下來需完成：乾淨的肩肘重疊素材、托腮與舉食指手掌差分、兩者的自然中間姿勢、可動頭部與手臂合為同一模型、其餘五姿勢、完整 20 組轉場與音訊同步量測。長時間效能、60 秒說話測試、Cubism Editor 回編、七姿勢示範與使用者質感評分均未完成。

目前結論：**開源工具可以產生標準模型並驅動嘴型與骨架；自動生成品質不足以直接替換現有角色動畫。** 保留 PSD2Live 作候選工具，尚未達到全案採用或整合門檻。
